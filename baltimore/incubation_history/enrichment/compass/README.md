# Complete public Maryland Community Compass incentives snapshot

Retrieved and imported on 2026-10-06 from [Find Funding](https://compass.maryland.gov/incentives/) and its public API.

## Coverage

- All **2,868 publicly listed programs** in the site's unfiltered default results and CSV export.
- Every program's detail endpoint: **38 original fields**, including descriptions, assistance, eligibility, geographic coverage, requirements, contacts, limits, deadlines, application process, sources, attachments, source timestamps, and featured metadata.
- **72,450 ordered property rows** preserve list values, empty lists, nulls, and featured metadata as flat database rows.
- **1,009 administrator labels** preserved as reported by Compass; normalized existing organization identities reused where unambiguous. There were no unresolved ambiguous administrators in this snapshot.
- **3,780 new organization IDs**, including program identities and previously unregistered administrator labels.
- **2,868 program context records**, with no monetary amounts.

Compass's public API prefilters low-quality and discontinued records; those excluded backend records are not exposed by this public page. This snapshot includes everything the page and export publicly served, not inaccessible backend data. External source and attachment URLs are preserved; linked documents were not individually downloaded or independently researched.

## Financial and identity semantics

Programs are registered as `funding_entities.entity_type = program`. Directory administrator labels are reported identities, not independent verification of legal incorporation or government status. The administrator reference remains separate from the program's legal entity, which is not inferred.

Limits are retained verbatim in `max_amount_int` and `max_amount_str`. They are directory disclosures, not actual awards, obligations, agency appropriations, or payments. No currency or award recipient is inferred. No financial facts or internal ledger transactions are created.

Program offerings use `organization_support_records.support_kind = terms`, with explicit source notes. They are available as relationship context and in public program reports, but do not inflate money totals or crowd the default relationship graph. Native program profiles link to the source's primary program URL, while Compass citations remain in the listing and context record. Administrator homepages are not guessed from the Compass host.

Source application flags, deadlines, public/private funding labels, and quality ratings are retained exactly. A recurring listing with a historical deadline is not automatically declared open. Featured content, including supplied HTML, is preserved as data and must be rendered as text or through an appropriate sanitizer, never implicitly executed.

## Storage and access

Migration `OrgPortal/org-worker/migrations/0076_compass_program_listings.sql` adds:

- `funding_program_listings`: scalar source fields, native organization references, source IDs, timestamps, and source SHA256.
- `funding_program_properties`: ordered eligibility, requirements, source/attachment URLs, assistance types, and flattened featured fields.

The existing public support endpoint adds `fundingPrograms.records`, `fundingPrograms.properties`, and `fundingPrograms.nextOffset`. It exposes the complete listing for a program and all listings for its administrator, using the existing `offset` parameter for pagination.

Example: [Downtown RISE PILOT public program report](https://lifetech.fyi/api/org/api/network/orgs/public/compass-downtown-rise-pilot/support). [MEA's public report](https://lifetech.fyi/api/org/api/network/orgs/public/maryland-energy-administration/support) includes all 31 Compass programs listed for MEA alongside its existing financial evidence.

Source archives and flat CSV exports are versioned as `.gz` files; uncompressed working copies are available alongside them locally. The large `apply.sql` is generated by the preparation script rather than committed. `featured.json` and `source-page.html` preserve the page's separate featured response and HTML.

## Repeatable extraction and verification

1. `scripts/fetch_compass_incentives.py` downloads the full CSV and all detail endpoints with four workers, retries, and a resumable JSONL archive. To take a fresh snapshot rather than resume, move the prior detail archive and its compressed copy aside first.
2. Export current `organizations`, `funding_entities`, and Compass `organization_source_identities` using the established read-only administrative D1 workflow.
3. `scripts/prepare_compass_portal_import.py --identities <export.json>` prepares native identities, flat program rows, property rows, and nonmonetary context records. Matching source IDs and existing identities prevents duplicate imports. Listing updates replace old property rows with the current complete source values.
4. Apply the reviewed SQL through the existing administrative workflow.

The complete SQL was tested twice locally for duplicate prevention and foreign keys. `scripts/verify_compass_archive.py <sqlite database>` independently reconstructs every imported source field: **108,984 comparisons passed**. Carriage returns and empty/null values are preserved. Nineteen relevant API/financing tests passed. Live verification confirmed all listing/property/context counts, no foreign-key failures, unchanged financial fact count (124), featured fields, MEA's 31 listings, and empty monetary totals for sampled directory-only program profiles. Receipts and verification summaries are adjacent files.
