Data notes

All locally available Git refs; both event-file paths. Latest record per occurrence. Recurring dates count separately. Map uses existing coordinates; missing, failed, generic-location and explicitly online coordinates are excluded. Coordinates may be approximate. Grid sizes are approximate near Baltimore. Categories use the first tag; “Other” combines smaller slices. Unknown organizers and cities remain visible. Dates use Eastern time. Counts reflect archived listings, not complete city activity.
