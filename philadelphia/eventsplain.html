Claude Code vs. Codex: Loops, Graphs, and Harnesses

## Claude Code vs. Codex: Loops, Graphs, and Harnesses

This is a casual pair-programming meetup for developers experimenting with Claude Code, Codex, and agentic coding workflows.
There is no formal presentation and no fixed curriculum. Bring a laptop, a repository, a side project, or a workflow you want to test. We will work in small groups, compare approaches, debug problems, and share what is working.

Possible areas to explore include:

* Building iterative coding-agent loops
* Comparing Claude Code and Codex on the same task
* Designing graph-based agent workflows
* Creating reusable coding harnesses
* Managing context across large repositories
* Running tests and validating agent-generated changes
* Using sandboxes, permissions, and approval steps
* Coordinating subagents or parallel tasks
* Measuring latency, token usage, cost, and completion quality
* Debugging failed or incomplete agent runs

You do not need to be an expert in either tool. This meetup is for people who want hands-on time to experiment, pair with other developers, and learn through building.
Bring something you are working on, or join someone else’s project.

## Claude Code Saturdays 🤖💻

**A weekly hands-on meetup for builders using Claude to write, refactor, and reason about code.**
Claude Code Saturdays is a relaxed, collaborative session for developers, founders, and tinkerers who want to explore what’s possible with Anthropic’s Claude for real-world coding tasks. Whether you’re prototyping a new app, improving an existing codebase, or just experimenting with AI-assisted development, this meetup is a space to learn by doing.

### What to Expect

* 🧑‍💻 **Live coding & pair-building** with Claude
* 🔍 **Prompting techniques** for better code generation and refactoring
* 🧠 **Reasoning-heavy tasks**: debugging, architecture, tests, and docs
* 🚀 **Show & tell**: share what you’re building or stuck on
* ☕ **Casual, friendly atmosphere**—bring your laptop and curiosity

### Who Should Attend

* Software engineers (any level)
* Startup founders and indie hackers
* Students learning to code with AI
* Anyone curious about AI-assisted development with Claude

You don’t need to be an expert—just a willingness to experiment and learn together.

### What to Bring

* A laptop
* A project, idea, or problem (optional but encouraged)
* Access to Claude (or just come observe and discuss)

The Agentic AI Risk Gap: From Autonomy to Accountability

[Register here to receive your access link!](https://ctrly.io/Jhhfv )

AI agents are moving beyond answering questions to writing code, accessing enterprise data, connecting to business tools, and executing workflows autonomously. While these capabilities can unlock significant productivity gains, they also introduce new security, governance, and accountability challenges.

**How can teams give AI agents the freedom to work effectively while ensuring they operate within the right boundaries?** From managing permissions and mitigating prompt injection risks to establishing human oversight, building trust in autonomous systems requires the right safeguards.

Join technology, AI, and security leaders for a practical discussion on deploying and scaling agentic AI responsibly. We'll explore emerging risks, proven safeguards, and strategies for balancing innovation with security and accountability.

**What You'll Learn**

* Emerging risks in agentic AI, including prompt injection, unintended actions, and data access concerns.
* Establishing permissions, guardrails, and human oversight for autonomous systems.
* Security best practices, including least-privilege access, monitoring, and auditability.
* Strategies for scaling agentic AI while balancing innovation, governance, and accountability.
